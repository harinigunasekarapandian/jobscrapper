# jobscrapper
A Python-based job scraper that fetches the latest remote job postings from the RemoteOK API and exports them into an Excel file.
This project is a Remote Job Scraping Tool that connects to the RemoteOK
 API and collects structured job postings in real-time. It extracts essential details such as job ID, company, position, location, tags, salary, and job URL, then saves the results into an Excel sheet (remoteok_jobs.xlsx) for further analysis.

Key Features:

Fetches the latest remote job listings from RemoteOK.

Extracts useful details:

Job ID

Date

Company Name

Job Position

Location

Tags (skills/technologies)

Salary (if available)

Job URL

Saves the data to a well-structured Excel file.

Simple and lightweight — powered by Python Requests & Pandas.

Tech Stack:

Python 3

Requests (to fetch data from RemoteOK API)

Pandas (to handle tabular data)

OpenPyXL (to write Excel files)

Use Cases:

Job seekers looking for up-to-date remote opportunities.

Data enthusiasts analyzing remote work trends.

Developers learning API integration and data export in Python.
